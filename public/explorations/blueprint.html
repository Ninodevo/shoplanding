Chapter01

What you actually get.

Four artifacts in one purchase. Two theme zips for the platforms that already cover ~85% of DTC, a portable spec your team can rebuild on anything, and a hosted intake form your buyers fill once.

01 · Shopify theme

A Shopify 2.0 theme that renders the system.

Drop into Online Store → Themes → Add → Upload, publish. The product page is the landing page is the entire store — built around a fixed block sequence that satisfies the 69 public CRO rules.

  • Shopify 2.0 (Online Store 2.0) JSON templates
  • All 7 blocks as theme sections you can reorder, but you shouldn't
  • Tokens-driven palette + type from the tweaks panel
  • Compatible with Shop Pay, BNPL, Subscriptions, Stamped, Klaviyo
shoplanding-shopify/
├ config/ │ ├ settings_schema.json │ └ settings_data.json ├ layout/ │ └ theme.liquid ├ templates/ │ ├ product.json // 7 blocks │ └ index.json // → product ├ sections/ │ ├ announcement.liquid │ ├ nav-sticky.liquid │ ├ product-overview.liquid │ ├ image-gallery.liquid │ ├ cta-area.liquid │ ├ social-proof.liquid │ ├ aov-boosters.liquid │ └ description.liquid ├ snippets/ // 20 partials └ assets/

02 · WooCommerce theme

A WooCommerce block theme — same anatomy, same blocks.

For founders on WordPress. Full-site editing means buyers tweak in the Site Editor without touching code. The block taxonomy maps 1:1 to the Shopify version so the rules stay rules, regardless of platform.

  • WooCommerce 9+ block theme (full-site editing)
  • Same 7 blocks as core/template parts
  • Patterns library so retailers copy/paste niche presets
  • Compatible with Stripe, Klarna, Affirm, Mailchimp
shoplanding-woo/
├ theme.json // tokens ├ style.css ├ functions.php ├ templates/ │ ├ single-product.html │ └ front-page.html ├ parts/ // 7 blocks │ ├ product-overview.html │ ├ image-gallery.html │ ├ cta-area.html │ ├ social-proof.html │ ├ aov-boosters.html │ └ description.html ├ patterns/ // niche presets └ assets/

03 · System spec

A portable JSON + Markdown spec — rebuild it anywhere.

The unlimited-stores license includes the system specification: every block, every rule, every recommended component, every niche preset, in machine-readable JSON with human-readable Markdown notes. Re-implement the anatomy on Hydrogen, Astro, Webflow, headless commerce, anywhere.

  • blocks.json — the 7-block taxonomy with rule references
  • rules.json — all 69 rules, with rationale + sources
  • presets/*.json — per-niche tokens + content defaults
  • spec.md — long-form rationale your CTO can review
system-spec.json
{ "version": "1.0.0", "blocks": [ { "slug": "cta-area", "rank": 4, "rules": 23, "components": [ "VariantSelector", "QuantitySelector", "BNPLPills", "UrgencyTimer", "FreeShipProgress", // ... ], "checklistRefs": [ "RA-001", "RA-002", /* …23 */ ] } ] }

04 · Tweaks panel

A hosted intake form — fill once, preview live, ship the zip.

After purchase, your buyer is sent to a hosted form with the tokens that drive the theme: brand name, palette, typography, niche preset, headline, the buy box copy. Live preview at /preview/<slug> updates as they fill. When they hit ship, the customised zips download.

  • Live preview URL — share with stakeholders before launch
  • Tokens-only changes (no theme editing required)
  • Copy slot for every block, defaults from the niche preset
  • Reusable for the lifetime of the license
